# 📝 SentenceBlank

SentenceBlank is a simple sentence completion web application built with **React**, styled using **Tailwind CSS**, and powered by **JSON Server** for handling mock backend data. Users can complete sentences by filling in missing words from a list of options or by typing them in manually.

---

## 🚀 Features

- 🧠 Sentence completion (fill-in-the-blank) exercises
- 📄 Questions stored in `db.json` and served using JSON Server
- 🎨 Responsive UI with Tailwind CSS
- 🔄 Real-time feedback (optional)
- 🔧 Easy to customize/add your own sentences

---

## 🛠 Tech Stack

- **React 19**
- **Tailwind CSS**
- **JSON Server**
- **Vite** for fast development and builds
- **Framer Motion** for animations
- **Lucide React** for icons
